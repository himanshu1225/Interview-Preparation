To install java, u need to install JDK.

JDK: Java development kit hota hai, jisme we have everything, like we can write code, we can compile it and finally we can run.

Companies like Oracle, Amazon etc have written their JDK, lagbhag sab same hi hota hai but ofcourse difference in license.

Pehle Oracle free me provide krta tha ab usne bhi paid kr diya.

1995 me sun microsystems company ne create kiya JAVA and in 2006 made it opensource as a project OPENJDK Project.

Open JDK Project ko reference maante huye sabhi version oracle and amazon ke likhe huye hai.

Oracle JDK yahi se aaya but usme additional features hai. Till now everyone was using ORACLE JDK but now everyone is moving to OPEN JDK as oracle has commericalised it.

Open JDK me source code mil jayega but Binaries are not present there.

Binaries: these are executable files which we can use directly on our OS.

Adoptium site: we can find binaries.


JDK: tools and libraries + JRE
     Iski help se java run hota.
     JDK
         ├── tools and libraries (Compiler, Debugger)
         └── JRE
              └── JVM
    finally code JVM me run hota hai.
